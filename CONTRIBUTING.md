# Contributing

This is a personal research repository with a single maintainer. Issues and
pull requests are accepted within the scope below.

## Issues

Open an issue for bugs, methodology questions, or reproducibility problems.
Include:

- What you were trying to do
- What happened vs. what you expected
- Minimal reproduction (notebook cell, command, or pseudo-code)
- Versions of Python and key libraries

## Pull Requests

1. Open an issue first for anything non-trivial.
2. One topic per PR.
3. Reference the issue in the PR description.

## Style

- Python: PEP 8. Type hints where they aid readability.
- Notebooks: clear narrative cells. Restart-and-run-all before commit.
- Commits: imperative mood, present tense.

## Scope

In scope: research, reproducibility, methodology, dataset documentation,
diagnostic notebooks.

Out of scope: productionizing the model, packaging for distribution,
hyperparameter sweeps without methodological justification.
